# Arkiv integration feedback

The installed SDK 1.0 returns typed values such as `StrValue` and `BytesValue` from a schema query. An early history view treated them as strings and byte arrays, which TypeScript rejected. Read `.value` and convert the replay hex to bytes before decoding. The strongest improvement would be a full React list-and-detail example that unwraps strings, numbers and byte payloads in one place.

The Rabdi public endpoint returned a valid empty list in a read-only smoke check. A funded writer transaction is pending configuration. The public endpoint is rate-limited, so demo deployments can use origin-restricted browser access keys.
