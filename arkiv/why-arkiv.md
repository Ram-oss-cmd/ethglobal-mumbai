# Why Arkiv

A public replay is useful after the lobby server forgets the room. Arkiv gives spectators a queryable record that another client can read directly using the schema and writer address. A private application database would require the original server's read API to remain available.

Live simulation inputs stay on the game server while the match runs. The archive stores the verified final input log and scores. Wallet sessions, signing keys, and human eligibility records stay private.
